# ☎ Contact Management System

A Python-based contact management application for adding, displaying, and searching contact records by phone number.

## ✨ Features

-  **Contact Registration:** Add new contacts with their first name, last name, phone number, and title.
-  **Contact Listing:** Display all registered contacts.
-  **Contact Search:** Find contacts using their phone number.
-  **Duplicate Prevention:** Prevent duplicate contact registrations based on phone number.
-  **Input Handling:** Handle invalid menu selections.
-  **Empty List Handling:** Display an appropriate message when no contacts are available.

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/ReyhanehMahmoudabadi/Contact_Management_System.git
```

**2. Navigate to the project directory**

```bash
cd Contact_Management_System
```

**3. Run the application**

```bash
python contact_main.py
```

## 🧪 Testing

The `contact_test.py` file contains manual test examples for the main contact management functions, including:

- Displaying the menu
- Collecting contact information
- Displaying contact records
- Searching for contacts by phone number

## 📝 Notes

- Contact records are stored in memory during program execution.
- All records are cleared when the application is closed.
- Each contact is identified by their phone number.
